# نموذج طلب الالتحاق بجامعة مؤتة — نسخة مبسطة

**هذه النسخة لا تستخدم Google Sheets أو Apps Script أو Cloudflare Worker أو قاعدة بيانات مخصصة.**

- **GitHub**: يحتفظ بالكود فقط.
- **Netlify**: ينشر الموقع ويستقبل بيانات الطلبات عبر Netlify Forms في لوحة حساب الإدارة.
- **CSV / Excel**: تنزيل نسخة من الطلبات من لوحة Netlify (Forms → اختر النموذج → Download as CSV).
- **PDF**: يُنشأ لدى الطالب عبر `pdf-generator.js` مباشرة في المتصفح دون فتح نافذة الطباعة أو الاتصال بخدمة PDF.
- **الورق**: طباعة نموذج معبّأ أو نموذج فارغ على A4.

## طريقة النشر (أقل عدد ممكن من الخطوات)

1. افتح مجلد `site` وارفع **محتوياته** إلى جذر مستودع GitHub، بحيث يكون ملف `index.html` في جذر المستودع، وليس داخل مجلد إضافي.
2. افتح https://app.netlify.com وأنشئ مشروعًا باستخدام **Import an existing project / Import from Git**، وحدد GitHub والمستودع.
3. إعدادات البناء: هذا موقع HTML عادي، **لا يحتاج Build command**. استخدم الجذر `.` كمجلد النشر أو اتركه فارغًا إذا كانت ملفات الموقع في الجذر.
4. انشر الموقع، ثم افتح **Forms** من لوحة Netlify وتأكد أن اكتشاف النماذج (Form detection) مُفعّل. إذا فعّلته بعد أول نشر، أعد نشر الموقع.
5. تأكد من ظهور النموذج باسم `mutah-admission` ثم أرسل **طلبًا تجريبيًا لا يحتوي بيانات حقيقية** باستخدام رابط Netlify النهائي. راجع تبويبي **Verified submissions** و **Spam submissions**.
6. نزّل البيانات من **Forms → mutah-admission → Download as CSV** واحفظها في قرص الإدارة المحمي. CSV قابل للفتح باستخدام Microsoft Excel.

**تنبيه:** إذا أبقيت الموقع على **GitHub Pages** فقط فلن تعمل ميزة حفظ البيانات في لوحة Netlify؛ GitHub Pages لا يقدم معالجة النماذج. GitHub يظل مستودع الكود وNetlify هو عنوان الصفحة التي يستخدمها الطلبة.

## الأزرار لدى الطالب

- **إرسال وحفظ البيانات إلكترونيًا**: يتحقق من الإلزاميات ثم يرسلها إلى Netlify Forms؛ بعد استجابة نجاح يُعرض نموذج A4.
- **معاينة وطباعة الطلب**: يعرض النموذج المعبأ دون إجراء أي إرسال.
- **حفظ PDF للطلب**: ينزّل ملف PDF مباشرة باستخدام كود خاص في `pdf-generator.js`، من دون استخدام مربع الطباعة. الناتج صورة عالية الدقة داخل صفحة PDF واحدة A4، وليس نص PDF قابلًا للبحث.
- **طباعة نموذج فارغ**: يعرض ورقة فارغة ويطلب الطباعة دون التحقق من أي حقل.
- **مسح البيانات**: يمسح ما تمت تعبئته محليًا.

ملاحظة: توقيع الطالب وختم خدمة العلم والصورة الشخصية تُستكمل على الورق. نوع الطلب يُختار تلقائيًا من رقم الطالب (1 تنافس، 4 موازي، 9 دولي) مع إمكان تغييره والتنبيه عند التعارض. بيانات الجامعات السابقة اختيارية. اسم الأب/الأم يُقبل برمجيًا من مقطعين على الأقل.

## أمن البيانات والخصوصية

1. **لا تنشر CSV أو ملفات الطلاب أو بياناتهم في GitHub**، لا في المستودع العام ولا في تعليقات Issues. المشروع المرفق يحتوي الكود فقط.
2. استخدم حساب Netlify مؤسسيًا، بكلمة مرور قوية و**مصادقة ثنائية MFA**، ولا تمنح صلاحيات لوحة الإدارة إلا للمخوّلين. استخدم رابط HTTPS الذي توفره Netlify.
3. البيانات الشخصية **ستمر بخوادم Netlify** وتُخزّن وفق شروط وأدوات الأمان الخاصة بها؛ اعتمد الخدمة رسميًا مع قسم تكنولوجيا المعلومات/الخصوصية في الجامعة قبل جمع بيانات فعلية. هذا ليس استضافة داخل الجامعة، ولا يثبت هوية الطالب وحده.
4. طبّق سياسة احتفاظ قصيرة ونسخ احتياطي دوري: نزّل CSV على تخزين جامعي محدود الصلاحيات ثم امسح السجلات القديمة بحسب سياسة الجامعة. لا تعتمد على لوحة الخدمة كأرشيف دائم وحيد.
5. Netlify Forms يوفر فلاتر للرسائل الآلية وحقل Honeypot في هذا النموذج. **هذه الإجراءات لا تمنع كل الإرسال العشوائي أو الانتحال**، ولا تحل محل التحقق من هوية الطالب. يمكن لاحقًا إضافة تحدي CAPTCHA بعد تجربة نسخة تجريبية.
6. يفضّل عدم تفعيل إشعارات تتضمن كل بيانات الطالب إلى بريد شخصي. استخدم البريد الرسمي إن احتجت إشعارات.
7. عند فتح CSV في Excel تعامل مع أي مدخلات غير متوقعة بحذر؛ فحقول النصوص مقدمة من المستخدمين.

## الاختبار قبل تعميم الرابط

- افتح الصفحة على Android وiPhone.
- جرّب رقمًا يبدأ بـ 1 ثم 4 ثم 9، والتبديل اليدوي للتأكد من ظهور التنبيه.
- جرّب إدخال اسم الأب والأم من مقطعين، وأربعة مقاطع لاسم الطالب.
- جرّب تنزيل PDF ومراجعته، وطباعة النموذج الفارغ.
- أرسل 2–3 طلبات وهمية؛ تأكد أنها وصلت إلى Netlify Forms وأن CSV يتضمن الحقول بشكل صحيح.
- جرّب فصل الإنترنت: يظل PDF المحلي ممكنًا، لكن إرسال الطلب سيرجع خطأ واضحًا.

## تفاصيل برمجية

- `index.html`: واجهة الإدخال ومخطط النموذج الورقي وتهيئة Netlify Forms.
- `style.css`: الاستجابة للهواتف وطباعة A4.
- `script.js`: التحقق، الإرسال، التبديل بين الإدخال والمعاينة، والطباعة التقليدية.
- `pdf-generator.js`: راسم PDF **مستقل بالكامل عن window.print**، يعتمد على Canvas وخوارزمية كتابة PDF بسيطة، بلا مكتبات خارجية.
- `logo.png`: الشعار من النموذج المرفق.

لا توجد أي كلمات مرور أو مفاتيح API داخل المشروع. لا توجد قاعدة بيانات مخصصة. يخزن Netlify الطلبات كإدخالات Form، ويُصدّرها CSV.
