# مساعد تعبئة نموذج طلب الالتحاق — V5.1

إعداد وبرمجة مصعب الطراونة

## الهدف
تعبئة نموذج طلب الالتحاق من الهاتف ثم معاينة/طباعة A4 أو حفظ ملف PDF. لا توجد قاعدة بيانات، ولا إرسال بيانات، ولا Netlify Forms أو Google Sheets.

## الاستخدام
- افتح `index.html` في المتصفح أو ارفع جميع الملفات إلى GitHub Pages.
- عبئ الحقول المطلوبة (الجامعات السابقة اختيارية).
- «معاينة وطباعة الطلب» يعرض النموذج الورقي ثم «طباعة الورقة».
- «حفظ PDF للطلب» ينشئ الملف مباشرة بكود `pdf-generator.js` دون نافذة الطباعة.
- «طباعة نموذج فارغ» يطبع ورقة فارغة دون الحاجة إلى تعبئة البيانات.

## GitHub Pages
ارفع ملفات `index.html`, `style.css`, `script.js`, `pdf-generator.js`, `logo.png` في جذر المستودع؛ ثم Settings > Pages > Deploy from a branch > main / root.

## الخصوصية
بيانات الطلب موجودة فقط في صفحة المتصفح أثناء تعبئتها، ولا تحفظ تلقائيًا بعد إغلاقها. ملف PDF يُنزّل على جهاز المستخدم. لا تعتمد على نسخة المتصفح كأرشيف.

## ملاحظة للطباعة
الإعداد A4 وحجم 100% ومن الأفضل إيقاف headers and footers في نافذة الطباعة.

## إقرار خدمة العلم
- يظهر مربع إقرار خاص لمراجعة مكتب خدمة العلم عندما تكون الجنسية أردنية والجنس ذكرًا.
- يجب على الطالب المعني تحديده قبل المعاينة أو حفظ PDF.
- لا يظهر للطالبات أو غير الأردنيين، ولا يضاف إلى النموذج الورقي (الموجود أصلًا فيه خانة ختم وتوقيع خدمة العلم).
- لا توجد أي اتصالات بحفظ خارجي أو Cloudflare أو GitHub API؛ الملفات محلية وتعمل على GitHub Pages مباشرة.
